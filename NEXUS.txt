Name: Exact Numbers
Summary: See the numbers behind the + and - marks in Survival Log's action tooltips: ~-12 satiety instead of two minus signs. The game's listed estimate, scaled by your character's own modifiers.

Description (BBCode):
When you hover an action on an object, Survival Log shows what it does to satiety, mood, energy and life, but only as one to three + or - marks. Exact Numbers swaps each mark for the number the game lists for it, marked with ~ because it is the game's estimate, not a measured amount. It only changes what the tooltip says; it never changes your character, the world or a save.

[size=5]Main features[/size]
[list]
[*][b]Numbers instead of marks[/b]: every + or - chip in an object's action menu tooltip and in the crafting table's product tooltip shows its listed number, such as ~-12 or ~+4.[/*]
[*][b]Your character's modifiers[/b]: the game scales every satiety, mood, energy and life change by your character's own ratios. By default the numbers include that scaling. Where it changed a number, the chip also carries the listed one as hover text. You can turn this off in the config.[/*]
[*][b]Safe fallback[/b]: if anything does not look the way the mod expects, the tooltip stays exactly as the game drew it.[/*]
[/list]
No hotkeys. Exact Numbers adds no data to your save and does not edit game files. You can remove it at any time.

[size=5]What the number is[/size]
Each action carries a short preview line in the game's data, such as Satiety:-12;Stamina:-20, and the game turns those numbers into marks. Exact Numbers shows the numbers themselves, with ~ in front. The preview is a summary written for the tooltip, not what the game applies: the real change comes from the action's effects while it runs. Some costs tick over time, some amounts are random, some gains fill a stat up to a set amount, every stat stops at zero and at its maximum, and food types, difficulty, conditions and buffs can change the amount. Exact Numbers does not read those effects yet, so every number carries the ~ and none is shown as exact. Max chips already show their number and are left alone. With the Action Speed mod, the numbers are not scaled to the changed action time.

[size=5]Known issues[/size]
[list]
[*]The first time a tooltip with a new action appears, its marks can show for a split second before the numbers arrive. A menu opened in the first couple of seconds after the game's UI loads can keep its marks.[/*]
[*]A number that is not whole is shown to one decimal.[/*]
[*]The mod's own text is in English.[/*]
[/list]
If a number looks wrong, please tell me which object and action showed it (see Feedback below).

[list]

[size=5]Installation[/size]
[list=1]
[*]Install [url=https://www.nexusmods.com/survivallog/mods/12]BepInEx[/url] [i](if no other mods were installed before, start the game once so BepInEx finishes setup, then quit)[/i].[/*]
[*]Put [font=Courier New]ExactNumbers.dll[/font] in the BepInEx&#92;plugins folder inside the game folder. Full path example:
[code]C:&#92;Program Files (x86)&#92;Steam&#92;steamapps&#92;common&#92;Survival Log&#92;BepInEx&#92;plugins&#92;ExactNumbers.dll[/code][/*]
[/list]

[size=5]Uninstall[/size]
Delete [font=Courier New]ExactNumbers.dll[/font] from the [font=Courier New]BepInEx&#92;plugins[/font] folder.

[size=5]Configuration[/size]
To turn the mod or the modifier scaling off, edit [font=Courier New]BepInEx&#92;config&#92;com.dev.survivallog.exactnumbers.cfg[/font] while the game is closed (see [url=https://github.com/AnExiledDev/SurvivalLog-ExactNumbers/blob/main/CONFIG.md]CONFIG.md[/url] for every setting). Changes apply at the next game start.
